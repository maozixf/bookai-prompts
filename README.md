# ChatGPT 职业 / 人设提示词速查

把 [bookai.top 职业提示词栏目](https://bookai.top/docs/category/chatgpt-prompt%E6%8F%90%E7%A4%BA%E8%AF%8D-%E8%81%8C%E4%B8%9A) 的 **234 条**提示词全量整理成一个可搜索的单页工具，另拆出 **652 条场景模板**。

**在线使用**：<https://maozixf.github.io/bookai-prompts/>

手机浏览器打开后「添加到主屏幕」，就跟一个 App 一样，不用装任何东西。

## 它能干什么

- **搜索**：输岗位、技能或任务都行，内置同义词映射 —— 搜「小红书」出社交媒体运营，搜「PRD」出产品经理，搜「SQL」出数据分析师
- **分类**：15 个职能大类，手机上默认收成一行，点「分类」展开
- **场景速查**：30 条「我要做的事 → 用哪个提示词」，点一下直接跳到对应卡片
- **复制**：单条模板点击即复制；角色 Prompt 可单独复制，也可连同全部模板一起复制

## 三类提示词，别选错

| 形态 | 数量 | 结构 | 适合 |
| --- | --- | --- | --- |
| 结构化人设 | 208 | 背景 / 技能 / 工作方式 / 输出格式 / 回答限制 | 通用，像给 AI 发岗位说明书 |
| 角色 + 问题清单 | 11 | 角色一句 + 按模块列好的现成提问 | 复制就能连问，不用自己想问题 |
| 角色 + 场景模板库 | 15 | 核心角色 Prompt + 6~7 模块、27~54 条场景模板 | 颗粒度最细，反复用 |

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 速查页（GitHub Pages 入口，单文件，离线也能用） |
| `ChatGPT职业提示词-分类速查.md` | 场景速查表 + 15 类清单 |
| `ChatGPT职业提示词-场景模板库合集.md` | 15 个模板库页面：核心角色 + 652 条模板 |
| `ChatGPT职业提示词-全文合集.md` | 234 条全文，每段一个代码块，适合导入知识库 |
| `prompts.json` | 结构化数据：分类、技能标签、`templates` 模板树、原文地址 |
| `scrape.py` `build.py` `parse_lib.py` `make_html.py` | 抓取 → 归类 → 解析模板 → 出页面 |

## 自己重新生成

```bash
python scrape.py      # 抓 234 个页面 → prompts_raw.json + raw/
python build.py       # 归类 + 解析模板库 → prompts.json + 三个 md
python make_html.py   # → ChatGPT职业提示词-速查.html
```

分类表在 `build.py` 的 `CATS`，搜索同义词在 `ALIAS`，模板表格解析在 `parse_lib.py`。
